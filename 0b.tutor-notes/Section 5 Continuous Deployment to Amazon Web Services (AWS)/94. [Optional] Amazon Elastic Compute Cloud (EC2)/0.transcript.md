# Amazon EC2 Overview

## What is EC2?

Amazon Web Services provides a service called Amazon Elastic Compute Cloud, commonly called **EC2**.

EC2 allows you to rent virtual computers in the cloud instead of buying and maintaining physical servers.

Typical use cases:

* Hosting applications
* Running Linux servers
* CI/CD agents
* Databases
* Development/testing environments
* Backend services

Many AWS services internally rely on EC2 infrastructure. 

---

# EC2 Core Concepts

## Instance

An **EC2 instance** is a virtual machine running in AWS.

Example:

* Ubuntu Linux server
* Amazon Linux server
* Windows server

AWS refers to these virtual machines as **instances**. 

---

## AMI (Amazon Machine Image)

An **AMI** is a preconfigured operating system image used to launch an instance.

Examples:

* Ubuntu Server 24.04
* Amazon Linux
* Windows Server
* Red Hat Enterprise Linux

The AMI defines:

* OS
* Preinstalled software
* Initial configuration



---

## Instance Type

The **instance type** defines the hardware resources of the VM.

Examples:

* `t2.micro`
* `t3.micro`
* `m5.large`

Resources affected:

* CPU
* RAM
* Network performance

For AWS Free Tier:

* `t2.micro` or `t3.micro` are commonly eligible. 

---

# Launching an EC2 Instance

## Basic Steps

### 1. Open EC2 Dashboard

From AWS Console:

* Search for EC2
* Open EC2 Dashboard



---

### 2. Launch Instance

Click:

* **Launch Instance**

Provide:

* Instance name
* Operating system
* AMI
* Instance type

Example used:

* Name: `my server`
* OS: Ubuntu
* AMI: Ubuntu Server 24.04
* Type: `t2.micro`



---

### 3. Key Pair

A **key pair** is used for SSH authentication.

Without a key pair:

* No remote SSH access from your local machine

However:

* AWS browser-based EC2 Instance Connect can still work.



---

### 4. Storage

Default example:

* 8 GB EBS volume

EBS acts like the virtual hard disk of the instance. 

---

### 5. Launch

Click:

* **Launch Instance**

AWS provisions the VM in the background. 

---

# Instance States

Important EC2 states:

| State      | Meaning             |
| ---------- | ------------------- |
| Pending    | Starting            |
| Running    | Active and usable   |
| Stopping   | Shutting down       |
| Stopped    | Powered off         |
| Terminated | Deleted permanently |



---

# Status Checks

AWS performs health checks.

Healthy instance:

* `2/2 checks passed`

This indicates:

* Hypervisor/network healthy
* OS reachable



---

# Connecting to EC2

## EC2 Instance Connect

AWS provides browser-based terminal access.

Process:

1. Select instance
2. Click `Connect`
3. Use `EC2 Instance Connect`
4. Open browser terminal

Ubuntu AMI default user:

```bash
ubuntu
```

# Stop vs Terminate

## Stop Instance

Equivalent to shutting down a computer.

Effects:

* VM stops running
* Can restart later
* EBS storage still exists
* Some resources may still incur charges



---

## Terminate Instance

Permanent deletion.

Effects:

* VM deleted
* Attached storage deleted
* Cannot restart later



---

# Elastic IP

An **Elastic IP** is a static public IP address allocated by AWS.

Purpose:

* Public internet connectivity

Unused Elastic IPs may incur charges. 

---

# Important Free Tier Notes

AWS Free Tier commonly includes:

* 750 hours/month of eligible micro instances

But charges can still happen if:

* Wrong instance type selected
* Extra storage allocated
* Elastic IP left unused
* Other billable services enabled
