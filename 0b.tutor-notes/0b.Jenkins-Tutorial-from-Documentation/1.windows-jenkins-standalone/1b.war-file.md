## what is .war file?

A `.war` file is a:

> Web Application Archive

It is a packaged Java web application used to deploy and run web-based Java applications.

The extension:

```text id="pcricj"
.war
```

stands for:

```text id="6v0uwl"
Web ARchive
```

---

# In Jenkins Context

The file:

```text id="moa2mk"
jenkins.war
```

contains the complete Jenkins web application.

Including:

* Jenkins core
* Web UI
* REST APIs
* Embedded web server
* Plugin framework
* Authentication system
* Java classes
* Static web content

When you run:

```powershell id="lq7t3m"
java -jar jenkins.war
```

Java executes the web application packaged inside the WAR.

---

# WAR File = ZIP File Internally

A WAR file is structurally similar to:

* `.zip`
* `.jar`

In fact:

```text id="ej5sjd"
WAR = specialized JAR file
```

You can rename:

```text id="j42edc"
jenkins.war
```

to:

```text id="yk48d4"
jenkins.zip
```

and extract it.

---

# Internal Structure of WAR File

Typical WAR structure:

```text id="4wxh0y"
myapp.war
│
├── WEB-INF/
│   ├── web.xml
│   ├── classes/
│   └── lib/
│
├── css/
├── js/
├── images/
├── index.jsp
└── META-INF/
```

---

# Important WAR Directories

---

# 1. `WEB-INF/`

Most important directory.

Contains:

| Item       | Purpose               |
| ---------- | --------------------- |
| `web.xml`  | Web app configuration |
| `classes/` | Compiled Java classes |
| `lib/`     | Dependency JARs       |

This directory is protected from direct browser access.

---

# 2. `WEB-INF/classes/`

Contains compiled Java bytecode:

```text id="3wwh1i"
.class files
```

Example:

```text id="c9m7r3"
WEB-INF/classes/com/company/App.class
```

---

# 3. `WEB-INF/lib/`

Contains dependency libraries.

Example:

```text id="82ru5u"
spring.jar
servlet-api.jar
hibernate.jar
```

In Jenkins WAR:

this contains huge numbers of libraries.

---

# 4. Static Web Content

WAR files contain frontend assets:

| Type   | Examples    |
| ------ | ----------- |
| HTML   | Web pages   |
| CSS    | Styling     |
| JS     | JavaScript  |
| Images | Icons/logos |

These are served to browsers.

# Traditional WAR Deployment

Historically WAR files were deployed into application servers like:

* Apache Tomcat
* Jetty
* WildFly
* GlassFish

Example:

```text id="1a3wpa"
Copy myapp.war into:
tomcat/webapps/
```

Tomcat automatically deploys it.

---

# Jenkins Special Case

Jenkins WAR is different because:

```text id="lrcw8q"
It contains its own embedded servlet container
```

Specifically:

```text id="1gkw5v"
Winstone
```

So Jenkins can run standalone:

```powershell id="24a6fe"
java -jar jenkins.war
```

without installing Tomcat.

# WAR vs JAR

---

# JAR File

```text id="4m3yhv"
Java ARchive
```

General Java application package.

Used for:

* Console apps
* Libraries
* Utilities

Example:

```text id="qhguhx"
app.jar
```

Run:

```powershell id="p8h0hf"
java -jar app.jar
```

---

# WAR File

```text id="ngzyw5"
Web ARchive
```

Specialized for web applications.

Contains:

* Servlets
* JSP
* Web configs
* Static content

---

# Comparison

| Feature          | JAR               | WAR           |
| ---------------- | ----------------- | ------------- |
| Full form        | Java Archive      | Web Archive   |
| Purpose          | General Java apps | Java web apps |
| Web content      | Usually no        | Yes           |
| Servlet support  | No                | Yes           |
| Deploy to Tomcat | Usually no        | Yes           |
| Example          | Spring utility    | Jenkins       |

---

# What Makes a WAR “Web Application”

WAR files contain Java web technologies like:

| Technology | Purpose                  |
| ---------- | ------------------------ |
| Servlet    | Backend request handling |
| JSP        | Dynamic web pages        |
| Filters    | Request interception     |
| WebSocket  | Real-time communication  |

These require a servlet container.

# Important Concept

A WAR file is NOT:

* Native Windows executable
* `.exe`
* Docker image
* Virtual machine

It is:

```text id="q6yc9u"
A packaged Java web application
```

requiring:

* JVM
* Servlet container

to execute.

---

# Very Important Distinction

The command:

```powershell id="wt5m1k"
java -jar jenkins.war
```

works because Jenkins WAR includes:

```text id="u5y6vy"
Embedded servlet container (Winstone)
```

Most traditional WAR files cannot run directly this way.

They require external servers like:

```text id="nvj2wj"
Tomcat
```
