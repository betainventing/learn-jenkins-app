## 1. Step-by-Step Evolution (Correct Approach)

### Step 1: Add Empty Stage (Syntax Validation)

```groovy
stage('Test') {
    steps {
        echo 'Test stage'
    }
}
```

Purpose:

* Validate pipeline structure
* Confirm stage appears in Jenkins UI 

---

### Step 2: Replace Echo with File Check

```groovy
stage('Test') {
    steps {
        sh 'test -f build/index.html'
    }
}
```

What this does:

* Verifies build artifact exists
* Fails pipeline if missing

Result:

* No output = success
* Error = file not found

---

## 2. Final Step: Add Test Execution

### Multi-line Shell Block

```groovy
stage('Test') {
    agent {
        docker {
            image 'node:18-alpine'
            reuseNode true
        }
    }
    steps {
        sh '''
        test -f build/index.html
        npm test
        '''
    }
}
```

---

## 3. Why Docker Is Required Here

* `npm test` needs:

  * Node.js runtime
  * npm

Without Docker:

* Depends on agent environment → unreliable

With Docker:

* Controlled Node.js environment (same as build)

Inside Test stage:

1. Docker container starts
2. Workspace is mounted
3. Commands run:

```bash
test -f build/index.html

```

4. Container stops

## 6. Critical Dependency Between Stages

### Why Build → Test order matters

* `npm ci` runs in **Build stage**
* Creates:

```text
node_modules/
```

Test stage depends on it.

---

### If You Reverse Order (Test → Build)

Failure:

```bash
npm test
→ ERROR: dependencies not found
```

Reason:

* `node_modules` missing

---

### Fix if Running Test First

You must add:

```bash
npm ci
```

1. Artifact validation → build/index.html exists

## 8. Important Clarification

> Tests do NOT require build

You *can* run:

```bash
npm ci
npm test
```

without build.

But:

* Your current pipeline assumes dependency on Build stage
* That’s why ordering matters

## 9. Final Clean Pipeline

```groovy
pipeline {
    agent none

    stages {
        stage('Build') {
            agent {
                docker {
                    image 'node:18-alpine'
                    reuseNode true
                }
            }
            steps {
                sh '''
                npm ci
                npm run build
                '''
            }
        }

        stage('Test') {
            agent {
                docker {
                    image 'node:18-alpine'
                    reuseNode true
                }
            }
            steps {
                sh '''
                test -f build/index.html
                npm test
                '''
            }
        }
    }
}
```
