To install the Stage View plugin in Jenkins:

1. Open the Jenkins dashboard.
2. Go to **Manage Jenkins** → **Plugins**.
3. In the left-side menu, select **Available plugins**.
4. Search for **Pipeline Stage View**.
5. Select the plugin and click **Install**.
6. After installation completes, restart Jenkins.

After the restart:

* Jenkins may take 1–2 minutes to come back online.
* If the page does not refresh automatically, perform a full browser refresh.
* If you see an error such as:

> localhost refused to connect

and Docker Desktop shows no running containers, it usually means the Jenkins container stopped during the restart.

Start Jenkins again using the same Docker command originally used to launch the container, for example:

```bash
docker start jenkins
```

or, if the container was created with `docker run` and removed automatically:

```bash
docker run ...
```

depending on how Jenkins was originally started.

The plugin installation itself is straightforward because Jenkins dynamically downloads the `.hpi` plugin package and installs it into the Jenkins home directory under:

```bash
/var/jenkins_home/plugins/
```

The restart reloads Jenkins with the new plugin initialized and registered in the UI.
