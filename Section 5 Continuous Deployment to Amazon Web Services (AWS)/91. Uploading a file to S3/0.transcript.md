## Uploading Files From Jenkins to Amazon S3

This lecture demonstrates the first real deployment action:

```text id="4d6xpr"
Jenkins
   ↓
AWS CLI
   ↓
Upload file to S3 bucket
```

using Amazon S3 and AWS Command Line Interface. 

---

# AWS S3 `cp` Command

The AWS CLI command used is:

```bash id="ljlwm3"
aws s3 cp
```

`cp` stands for:

```text id="9jlwm8"
copy
```

It copies:

* Local → S3
* S3 → Local
* S3 → S3

depending on source and destination paths.

---

# Basic Upload Syntax

General syntax:

```bash id="jlwm4r"
aws s3 cp <local-file> <s3-path>
```

Example:

```bash id="jlwm0t"
aws s3 cp index.html s3://my-bucket/index.html
```

Meaning:

| Part         | Description              |
| ------------ | ------------------------ |
| `index.html` | Local file               |
| `s3://`      | S3 protocol prefix       |
| `my-bucket`  | Bucket name              |
| `index.html` | Object key inside bucket |

# Full Pipeline Example

Pipeline section:

```groovy id="jlwm2b"
stage('AWS') {

    environment {
        AWS_S3_BUCKET = 'learn-jenkins-20240518-1820'
    }

    agent {
        docker {
            image 'amazon/aws-cli'
            args '--entrypoint=""'
        }
    }

    steps {

        withCredentials([
            usernamePassword(
                credentialsId: 'my-aws',
                usernameVariable: 'AWS_ACCESS_KEY_ID',
                passwordVariable: 'AWS_SECRET_ACCESS_KEY'
            )
        ]) {

            sh '''
                aws --version

                echo "Hello S3" > index.html

                aws s3 cp index.html s3://$AWS_S3_BUCKET/index.html
            '''
        }
    }
}
```


# Important S3 Detail

S3 does not truly have directories like Linux filesystems.

This path:

```text id="mjlwm5"
s3://bucket/index.html
```

is actually:

```text id="rjlwm0"
Bucket = bucket
Object Key = index.html
```

Folders are logical key prefixes.

Example:

```text id="jjlwm6"
images/logo.png
```

is simply an object key string.

# Important Operational Consideration

Current upload behavior:

```bash id="4jlwm9"
aws s3 cp
```

uploads only one file.

Real frontend applications usually contain:

* HTML
* CSS
* JS bundles
* Images
* Fonts
* Assets

Real deployments commonly use:

```bash id="xjlwm4"
aws s3 sync
```

instead.

Example:

```bash id="2jlwm0"
aws s3 sync dist/ s3://my-bucket
```

This synchronizes entire directories.

---

# Why `sync` Is Commonly Preferred

`sync` can:

* Upload new files
* Update changed files
* Skip unchanged files
* Optionally delete removed files

Much more suitable for production deployments.
