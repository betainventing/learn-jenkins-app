# Static Website Hosting with S3

The deployment pipeline automatically uploaded website files into an S3 bucket.

S3 then served:

* HTML
* CSS
* JavaScript
* Images

directly to users through a web endpoint.

Advantages:

* Low cost
* Simple setup
* Highly scalable
* No server management

Limitations:

* No backend execution
* No server-side rendering
* Limited dynamic functionality

# Domain Name Mapping

* Custom domain

## Concepts Covered

* Users

* Who can access AWS

# Why IAM Matters

The deployment pipeline required secure authentication to AWS.

Instead of using root credentials:

* IAM users/access keys were used

This is critical because CI/CD systems need:

* Programmatic access
* Controlled permissions
* Auditable security boundaries
