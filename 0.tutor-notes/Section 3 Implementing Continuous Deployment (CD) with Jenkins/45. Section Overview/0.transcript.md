This section is introducing the **deployment** phase of the CI/CD lifecycle.

Key concepts being introduced:

* **Deployment**
  Taking the application that was developed and making it accessible on the internet/cloud.

* **Cloud Hosting Platform**
  The course uses Netlify for hosting the website.
  Netlify is widely used for:

  * static websites
  * frontend applications
  * JAMstack deployments
  * automatic deployments from Git repositories

* **Continuous Delivery (CD)**
  The pipeline automatically:

  1. builds the application
  2. runs tests
  3. prepares it for deployment

  But production deployment may still require manual approval.

* **Continuous Deployment**
  Extends continuous delivery further:

  * every successful change is automatically deployed to production
  * no human approval step required

* **CI/CD Pipeline Goal**
  By the end of the section, the workflow becomes:

  ```text
  Developer pushes code
        ↓
  CI pipeline triggers
        ↓
  Install dependencies
        ↓
  Build application
        ↓
  Run tests
        ↓
  Deploy to Netlify
        ↓
  Website becomes live on the internet
  ```

What “float in the cloud” means technically:

* The website files are hosted on distributed infrastructure
* Users access the site through HTTPS over the internet
* Netlify handles:

  * hosting
  * CDN delivery
  * SSL certificates
  * deployment automation
  * rollback/versioning

Typical DevOps concepts involved in this section:

| Concept            | Purpose                                 |
| ------------------ | --------------------------------------- |
| GitHub integration | Trigger deployments from Git pushes     |
| Build automation   | Create production-ready artifacts       |
| CI                 | Validate code automatically             |
| CD                 | Automate release/deployment process     |
| Hosting platform   | Serve the application publicly          |
| Cloud deployment   | Move app from local machine to internet |
