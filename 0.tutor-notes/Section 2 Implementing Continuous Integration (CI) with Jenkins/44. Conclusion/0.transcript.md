## 2. What Happens Internally (End-to-End Flow)

```text
Trigger → Jenkins Controller
        → Select Agent
        → Clone Repository
        → Start Docker Container(s)
        → Execute Stages
        → Generate Artifacts
        → Publish Reports
        → Cleanup Containers
```
