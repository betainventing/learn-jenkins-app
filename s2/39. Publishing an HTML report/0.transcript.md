### Publishing Playwright HTML Reports in Jenkins

---

## 1. Enable HTML Report Generation

Update your Playwright command:

```bash
npx playwright test --reporter=html
```

Result:

* Generates report in:

```text
playwright-report/
└── index.html
```

---

## 2. Problem: Report Not Opening in Jenkins

When opening `index.html` from workspace:

* Blank page
* Browser console error: **Content Security Policy (CSP)**

Reason:

* Jenkins blocks scripts inside HTML (security feature)
* Prevents XSS attacks from untrusted files

---

## 3. Temporary Fix: Disable CSP (Lab Only)

Go to:

```
Manage Jenkins → Script Console
```

Run script (from course resource)

Effect:

* Allows HTML reports to render

⚠️ Do NOT use this in production Jenkins
→ weakens security model

---

## 4. Proper Solution: Publish HTML Report

Instead of manually opening files, use Jenkins plugin.

---

## 5. Install Plugin

Go to:

```
Manage Jenkins → Plugins → Available Plugins
```

Search:

```
HTML Publisher
```

Install it.

---

## 6. Configure HTML Publishing in Pipeline

### Step 1: Identify Report Path

From workspace:

```text
playwright-report/index.html
```

---

### Step 2: Add Post Action

```groovy
post {
    always {
        publishHTML([
            reportDir: 'playwright-report',
            reportFiles: 'index.html',
            reportName: 'Playwright HTML Report'
        ])
    }
}
```

---

## 7. Full Example (E2E Stage + HTML Report)

```groovy
pipeline {
    agent none

    stages {
        stage('E2E') {
            agent {
                docker {
                    image 'mcr.microsoft.com/playwright:v1.40.0-jammy'
                    reuseNode true
                }
            }
            steps {
                sh '''
                npm ci

                node_modules/.bin/serve -s build &
                sleep 10

                npx playwright test --reporter=html
                '''
            }
        }
    }

    post {
        always {
            publishHTML([
                reportDir: 'playwright-report',
                reportFiles: 'index.html',
                reportName: 'Playwright HTML Report'
            ])
        }
    }
}
```

---

## 8. Result in Jenkins UI

After build:

* Left sidebar shows:

```text
Playwright HTML Report
```

Click → opens report directly

---

## 9. What You Gain

Without publishing:

```text
Workspace → navigate folders → open file → blocked by CSP
```

With publishing:

```text
Single click → clean UI report
```

## 10. Key Insight

You now have **two reporting systems**:

### 1. JUnit (XML)

* Machine-readable
* Used for trends, pass/fail stats

### 2. HTML Report

* Human-readable
* Detailed UI (screenshots, steps, traces)

---

## 11. Real DevOps Practice

Production pipelines typically:

```text
JUnit → pipeline status & metrics  
HTML → debugging failures  
```

---

## 12. Common Mistakes

❌ Wrong directory:

```groovy
reportDir: 'playwright-report/'   // trailing slash sometimes breaks
```

❌ Wrong file name:

```groovy
reportFiles: 'report.html'  // must be index.html
```

❌ Plugin not installed
