### End-to-End (E2E) Tests with Playwright in Jenkins

---

## 1. What Changes Compared to Unit Tests

Unit tests:

```text
Test code directly
```

E2E tests:

```text
Require running application (HTTP server)
```

So pipeline must:

```text
Build → Start App → Run Playwright Tests
```

---

## 2. Key Requirement

You **must run a server** before executing:

```bash
npx playwright test
```

Reason:

* Playwright interacts with a **live application**, not source code 

---

## 3. Core Problem You Encountered

### Issue 1: Permission Error

```bash
npm install -g serve
→ EACCES error
```

Cause:

* Global install requires elevated permissions
* Docker container runs as non-root

---

### Correct Fix (Not Root)

❌ Wrong:

```groovy
args '-u root:root'
```

→ breaks workspace permissions later

---

✅ Correct:

* Install locally:

```bash
npm install serve
```

* Use binary:

```bash
node_modules/.bin/serve
```

---

## 4. Issue 2: Pipeline Hanging

Problem:

```bash
serve -s build
```

* Starts server
* Runs forever
* Blocks pipeline

---

### Fix: Run in Background

```bash
node_modules/.bin/serve -s build &
```

---

## 5. Issue 3: Race Condition

Problem:

* Server starts asynchronously
* Tests start immediately → fail

---

### Fix: Add Delay

```bash
sleep 10
```

---

## 6. Final E2E Stage

```groovy
stage('E2E') {
    agent {
        docker {
            image 'mcr.microsoft.com/playwright:v1.40.0-jammy'
            reuseNode true
        }
    }
    steps {
        sh '''
        npm ci

        node_modules/.bin/serve -s build &
        sleep 10

        npx playwright test
        '''
    }
}
```

---

## 7. Execution Flow

```text
Start container
→ Install dependencies
→ Start server (background)
→ Wait 10s
→ Run Playwright tests
→ Exit
→ Container stops
```

---

## 8. JUnit Report Conflict (Important)

Problem:

* Unit tests + E2E tests both write:

```text
test-results/junit.xml
```

Result:

* One overwrites the other
* Jenkins fails:

```text
No test report files were found
```

---

## 9. Fix: Separate Report Paths

Example:

```text
Unit tests → test-results/
E2E tests → e2e-results/
```

Update Jenkins:

```groovy
post {
    always {
        junit 'test-results/*.xml'
        junit 'e2e-results/*.xml'
    }
}
```

---

## 10. Alternative Fix

Move reporting inside stages:

```groovy
stage('Test') {
    ...
    post {
        always {
            junit 'test-results/*.xml'
        }
    }
}
```

---

## 11. Key Debugging Lessons

### When pipeline hangs:

```text
Check for long-running processes (servers)
```

---

### When permission errors occur:

```text
Avoid root → fix installation method
```

---

### When reports fail:

```text
Check file paths + overwrites
```

## 12. Final Insight

You just introduced:

```text
Static CI → Dynamic CI (runtime validation)
```

* Unit tests → validate logic
* E2E tests → validate real behavior

## 13. Real DevOps Pattern

Production pipelines:

```text
Build
→ Unit Test
→ Integration Test
→ E2E Test
→ Deploy
```

---

## 14. Critical Mental Model

```text
Container = runtime
Workspace = shared state
Server = temporary process
```

* Server must not block pipeline
* Reports must not conflict

---

## 15. Common Mistakes to Avoid

❌ Running server in foreground
❌ Using root user blindly
❌ Overwriting test reports
❌ Forgetting delay before tests
