Architecturally, the pipeline evolved through several maturity stages:

```text id="9p2r0x"
basic pipeline
→ deployment pipeline
→ validated deployment pipeline
→ production verification pipeline
→ continuous deployment pipeline
```

One of the most important concepts introduced was:

```text id="wgr7oj"
successful deployment != correct deployment
```

which is why:

* version validation
* E2E verification
* deployment integrity checks
  became central parts of the pipeline.


