This assignment is asking you to implement a:

# Manual Production Approval Gate

directly inside your real CI/CD pipeline.

The intended pipeline flow becomes:

```text id="ah3jlwm"
Build
   ↓
Tests
   ↓
Deploy Staging
   ↓
Approval Step
   ↓
Deploy Production
```

---

# What You Need To Add

You should insert a new stage:

```text id="k8jlwm"
approval
```

between:

```text id="2j7m1f"
deploy staging
```

and:

```text id="1lx2dp"
deploy prod
```

---

# Core Jenkins Feature

You will use:

```groovy id="jlwmx1"
input
```

inside the approval stage.

---

# Recommended Structure

Conceptually your pipeline should resemble:

```groovy id="jlwmx2"
stage('Approval') {
    steps {
        timeout(time: 1, unit: 'HOURS') {
            input(
                message: 'Ready to deploy to production?',
                ok: 'Yes, deploy to production'
            )
        }
    }
}
```

---

# Why Timeout Should Be Included

Without timeout:

```text id="jlwmx3"
Pipeline waits forever
```

This is bad operationally.

Timeout prevents:

* abandoned builds
* stale deployments
* suspended pipelines indefinitely consuming resources

---

# Why Approval Goes After Staging

This is extremely important architecturally.

The flow should be:

```text id="jlwmx4"
Deploy staging
    ↓
Validate staging
    ↓
Human review
    ↓
Deploy production
```

NOT:

```text id="jlwmx5"
Deploy production
    ↓
Approval
```

because approval must happen before production exposure.

---

# What Will Happen During Execution

When pipeline reaches approval stage:

```text id="jlwmx6"
Pipeline pauses
```

Jenkins UI will display:

* Proceed button
* Abort button

---

# If You Click Proceed

Pipeline continues:

```text id="jlwmx7"
Deploy production
```

---

# If You Click Abort

Pipeline status becomes:

```text id="jlwmx8"
ABORTED
```

and production deployment never happens.

---

# Important Real-World Meaning

This assignment is implementing:

# Controlled Promotion

The staging deployment becomes a candidate release.

Production deployment only happens after approval.

This is a foundational enterprise CI/CD deployment model.
