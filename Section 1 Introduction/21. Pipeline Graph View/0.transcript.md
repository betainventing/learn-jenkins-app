In Jenkins Pipeline jobs, the **Pipeline Graph View** is an alternative visualization of the pipeline execution flow.

## What It Is

The Pipeline Graph View displays:

* All stages of the pipeline in a graphical flow
* Execution order of stages
* Status of each stage
* Logs and actions inside each stage

It is available from the pipeline job menu under:

* **Stages**

This feature is newer compared to the traditional Stage View plugin.

---

## What You Can See

Inside the graph view, Jenkins shows:

* Entire pipeline structure
* Stage-by-stage execution
* Individual steps executed in each stage
* Console output related to those steps

Example:

If a stage runs:

```groovy
stage('Build') {
    steps {
        sh 'npm install'
        echo 'Build completed'
    }
}
```

The graph view lets you inspect:

* Shell commands executed
* Printed messages
* Success/failure of steps
* Timing information

You can expand steps to inspect detailed logs.

---

## Example Stages

Typical stages shown:

* Build
* Test
* Deploy

Clicking a stage shows:

* Executed shell scripts
* Output logs
* Jenkins step details
* Errors if any occurred

---

## Additional Options Available

From the Pipeline Graph View interface, Jenkins also provides quick actions such as:

* Start Build
* Open Console Output
* Configure Job
* Replay Pipeline (if enabled)
* View Pipeline History

---

## Difference Between Stage View and Pipeline Graph View

| Feature                | Stage View               | Pipeline Graph View         |
| ---------------------- | ------------------------ | --------------------------- |
| UI Style               | Traditional table layout | Modern graphical layout     |
| Pipeline Visualization | Basic                    | Detailed flow visualization |
| Step-Level Inspection  | Limited                  | Better visibility           |
| User Experience        | Simple                   | More interactive            |
| Recommended for        | Basic monitoring         | Detailed pipeline analysis  |

---

## Why It Matters

The Pipeline Graph View becomes especially useful when pipelines grow larger and include:

* Parallel stages
* Multiple agents
* Complex CI/CD workflows
* Conditional execution
* Long deployment pipelines

It helps quickly identify:

* Which stage failed
* Which step caused failure
* Execution duration
* Pipeline bottlenecks

---

## Important Note

Even though many tutorials may continue using:

* Console Output
* Classic Stage View

the Pipeline Graph View is increasingly becoming the preferred modern interface in Jenkins for visualizing pipeline execution.
